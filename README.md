# Python-based-command-line-text-adventure-game-engine

一个基于 Python 命令行运行的文字冒险游戏引擎，所有剧情内容通过 `game.json` 文件定义。引擎负责解析 JSON 内容，提供打字机特效、选项分支、存档读档、自动播放、历史回忆、好感度系统等交互功能。玩家只需按回车和数字键即可体验故事。

## 适用场景

- **极低配设备**：纯文本命令行运行，无需图形界面，内存占用极小，适合老旧电脑、嵌入式设备或服务器终端。
- **极简交互风格爱好者**：喜欢纯粹文字叙事，没有复杂 UI 的玩家。
- **二次创作**：无需编程基础，只需编辑 JSON 文件即可创作自己的视觉小说/文字冒险游戏。同时提供 AI 提示词，可让 AI 辅助生成剧情 JSON。

## 引擎功能

### 核心交互
- **打字机效果**：文字逐字显示，按回车可立即显示当前段剩余内容。
- **逐段推进**：场景文本可按 `\n` 分割为多个段落，每段显示后需按回车继续。
- **选项分支**：场景可包含多个选项，玩家输入数字选择，根据选项执行效果并跳转场景。
- **自动播放**：输入 `a` 开启/关闭自动播放，自动播放时每段显示后等待设定间隔（默认 3 秒，可调），期间按回车可取消自动播放。

### 游戏机制
- **角色属性系统**：可在 `characters` 中定义任意属性（如好感度），支持数值比较和增减。
- **标志系统**：包含全局标志（跨场景变量）和角色私有标志，可用于条件判断和剧情分支。
- **条件系统**：支持属性比较、全局标志判断、角色标志判断，可组合使用，选项仅当所有条件满足时显示。
- **效果系统**：支持增加/设置属性、设置全局/角色标志、增加全局数值标志等，选择选项后自动执行。
- **玩家自定义输入**：在文本中使用 `{input:变量名:提示文字}` 插入输入点，允许玩家起名、输入自定义内容，之后文本中 `{变量名}` 会被替换。

### 存档与读档
- **自动存档**：每次场景切换后自动保存到槽位 0。
- **手动存档**：输入 `s` 打开存档界面，可选择槽位 1~9 保存，支持覆盖确认。
- **读档**：输入 `l` 打开读档界面，可选择任意有存档的槽位（包括自动存档槽位 0），读档后显示最近 `RECALL_SIZE` 条历史回忆（默认 20 条，可修改）。
- **历史对齐**：读档时自动截断历史，确保回忆片段与当前场景内容不重复。

### 辅助功能
- **历史回忆**：输入 `h` 显示最近对话记录，可用作回顾剧情。
- **主界面**：启动后显示操作说明，可在此进行存档、读档、查看历史（需已有历史），按回车开始新游戏。
- **内容缺失引导**：首次运行若未找到 `game.json`，会自动在脚本同目录生成示例 JSON 和 `system prompt.txt` 提示词文件，并询问玩家是否查看编写规则。

## 环境要求

- Python 3.6+
- Windows / Linux / macOS（Windows 下需使用支持 UTF-8 的终端，或引擎已自动设置编码）

---

## 快速开始

1. 将 `gal.py` 放在任意目录，确保同目录下没有 `game/` 文件夹，或 `game/game.json` 不存在。
2. 运行 `python gal.py`。
3. 若缺少 `game.json`，引擎会自动创建示例文件并生成提示词文件，按提示操作。
4. 编辑 `game/game.json` 定义你的故事。
5. 重新运行 `python gal.py`，按回车开始游戏。

## `game.json` 格式详解

`game.json` 是游戏内容的唯一来源，其顶层结构包含四个部分：

```json
{
  "meta": { ... },
  "characters": { ... },
  "global_flags": { ... },
  "scenes": { ... }
}
```

### `meta`（可选）

游戏元信息，仅用于说明，引擎不会使用。例如：

```json
"meta": {
  "title": "示例游戏",
  "version": "1.0"
}
```

### `characters`（必需）

角色定义对象，键为角色 ID（字符串），值为角色属性对象。每个角色可包含：

- `display_name`：显示名称（可选）
- `attributes`：属性字典，初始值为数字，如 `"好感度": 0`
- `flags`：角色私有标志字典，初始值任意类型

示例：

```json
"characters": {
  "星见": {
    "display_name": "七瀬 星见",
    "attributes": { "好感度": 0 },
    "flags": { "已见面": false }
  }
}
```

### `global_flags`（可选）

全局标志，跨场景的变量，初始值为任意类型。

示例：

```json
"global_flags": {
  "周目数": 1
}
```

### `scenes`（必需）

场景集合，必须包含 `"start"` 场景作为游戏开始。场景有两种类型：

#### 纯对话场景

无选项，按回车跳转到下一个场景。

```json
"scene_id": {
  "text": "对话文本，可用 \\n 分隔多段",
  "next_scene": "下一个场景ID"
}
```

#### 选项场景

包含选项数组，每个选项可能包括条件、效果。

```json
"scene_id": {
  "text": "场景文本",
  "options": [
    {
      "text": "选项文字",
      "next_scene": "跳转场景ID",
      "conditions": [ ... ],   // 可选
      "effects": [ ... ]       // 可选
    }
  ]
}
```

### 条件系统（conditions）

条件用于控制选项是否可见。支持三种类型：

#### 1. 属性条件

```json
{ "type": "attribute", "target": "角色ID", "attribute": "属性名", "operator": ">=", "value": 10 }
```

支持的运算符：`>`、`>=`、`<`、`<=`、`==`、`!=`。

#### 2. 全局标志条件

```json
{ "type": "global_flag", "key": "标志名", "operator": "==", "value": true }
```

若省略 `operator`，默认为 `==`。

#### 3. 角色标志条件

```json
{ "type": "flag", "target": "角色ID", "key": "标志名", "value": true }
```

若省略 `target`，则检查全局标志。

### 效果系统（effects）

选项被选择后按顺序执行效果。支持五种类型：

#### 1. 增加属性值

```json
{ "type": "add_attribute", "target": "角色ID", "attribute": "属性名", "value": 1 }
```

`value` 可为负数。

#### 2. 设置属性值

```json
{ "type": "set_attribute", "target": "角色ID", "attribute": "属性名", "value": 5 }
```

#### 3. 设置全局标志

```json
{ "type": "set_global_flag", "key": "标志名", "value": true }
```

#### 4. 设置角色标志

```json
{ "type": "set_flag", "target": "角色ID", "key": "标志名", "value": true }
```

若省略 `target`，则等同于设置全局标志。

#### 5. 增加全局标志数值

```json
{ "type": "add_global_flag", "key": "标志名", "value": 1 }
```

### 玩家自定义输入与变量替换

在任意文本（场景文本或选项文本）中插入：

```
{input:变量名:提示文字}
```

例如：

```json
"text": "你叫{input:player_name:请输入你的名字}，今年16岁。"
```

运行时引擎会暂停并显示提示，玩家输入内容存入变量。之后文本中所有 `{player_name}` 将被替换为输入值。若变量已存在（读档后），则不再询问。

## 编写教程

### 1. 设计故事结构

将剧情拆解为多个场景，明确哪些场景有选择分支，哪些是纯对话。绘制简单的流程图有助于管理。

### 2. 创建角色和属性

在 `characters` 中定义所有出场角色，并为需要积累的数值（如好感度）创建属性。

### 3. 编写场景

从 `"start"` 开始，每个场景设置 `text` 和 `next_scene`。若需要分支，添加 `options` 数组，每个选项指定 `next_scene`、可选 `conditions` 和 `effects`。

### 4. 添加条件与效果

- **选项可见条件**：使用 `conditions` 数组，例如好感度 ≥ 5 才显示某选项。
- **选择后影响**：使用 `effects` 数组，增减属性或设置标志。

### 5. 使用玩家输入

在开场或需要自定义名称时，使用 `{input:变量名:提示}` 标记，后续文本中用 `{变量名}` 引用。

### 6. 测试与存档

运行引擎测试所有分支，使用 `s` 存档、`l` 读档验证状态恢复是否正确。

## AI 辅助创作

引擎首次运行缺少 `game.json` 时，会在脚本同目录生成 `system prompt.txt` 文件。该文件包含详细的 AI 提示词，指导 AI 将小说内容转换为符合本引擎规范的 JSON 文件。你可以将小说原文和提示词提供给 ChatGPT 等 AI 工具，快速生成 `game.json`。

**使用流程**：

1. 准备小说文本。
2. 复制 `system prompt.txt` 中的提示词，附加小说内容发送给 AI。
3. AI 会输出完整的 JSON 文件。
4. 将 AI 输出的内容保存为 `game/game.json`，运行引擎测试。

## 可调整参数

引擎类中有一组可调参数（位于 `GalgameEngine` 类开头）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `RECALL_SIZE` | 20 | 历史回忆显示条数 |
| `SAVE_SLOT_COUNT` | 9 | 手动存档槽位数（不含自动存档） |
| `TYPE_SPEED` | 0.03 | 打字机每字符间隔（秒） |
| `AUTO_PLAY_INTERVAL` | 1.0 | 自动播放时每段等待时间（秒） |

直接修改这些值即可改变引擎行为。

---

## 注意事项

- JSON 文件必须使用 UTF-8 编码保存，推荐使用 VS Code 等编辑器。
- 场景 ID 必须唯一，且不能与 `"end"` 冲突（`"end"` 为默认结束场景，也可定义自己的结束场景）。
- 所有字符串必须使用双引号，文件末尾无尾逗号。
- 若使用 AI 生成 JSON，请检查语法正确性。
